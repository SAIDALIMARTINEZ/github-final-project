# Contributing to the Simple Interest Calculator

Thank you for your interest in this project! Everyone in the community is welcome to help.

## How to contribute

Fork this repository, create a new branch for your change, and test it by running ./simple-interest.sh.

Commit with a clear message, push your branch, and open a Pull Request.

## Ideas for contributions

Report bugs or typos by opening an issue. Improve the documentation. Add input validation to the script. Suggest new features, such as compound interest.

## Be kind

Please follow our Code of Conduct (CODE_OF_CONDUCT.md) in every interaction.
